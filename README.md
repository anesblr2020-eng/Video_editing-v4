# مختبر الصوت — إعادة البناء، المرحلة 01

هذه نسخة تأسيسية منفصلة عن نظام الموشن القديم. تحتوي فقط على واجهة جديدة ومحرك التفريغ الصوتي ومحرك قص الصمت.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

يتطلب قص الصمت وجود FFmpeg في النظام. قد يحتاج التفريغ المحلي إلى تنزيل نموذج Faster-Whisper، وقد تتوفر مسارات تفريغ سحابية حسب إعدادات `transcriber.py` ومفاتيح الخدمة.

## ما تم الاحتفاظ به
- `transcriber.py`: تفريغ الكلام والتوقيتات وإصلاحات النص ذات الصلة بالصوت.
- `auto_cut.py`: تحليل فترات الصمت وقصها.

## ما لم يعد ضمن تطبيق التشغيل
محركات الصور والمشاهد والموشن والتأثيرات والانتقالات والقوالب والمصدّرات القديمة. لم تُنقل إلى هذه النسخة النظيفة.

## الحدود الحالية
- لم يُبنَ محرك المشاهد المرئية بعد؛ هذه مرحلة الصوت فقط كما طُلب.
- لا يمكن اعتبار نجاح التفريغ أو القص مؤكداً على كل بيئة قبل اختبار الملف فيها، لأن ذلك يتأثر بتوفر FFmpeg والنماذج ومكتبات النظام.
- الواجهة تحتاج اختبار تشغيل فعلي على بيئة تحتوي على Streamlit، وهو غير متوفر في بيئة البناء الحالية.

## الإعدادات التلقائية في المرحلة 02
لا تظهر إعدادات صوت في كل مرة. التفريغ مضبوط تلقائياً على نموذج `small` للعربية مع وضع الدارجة الجزائرية. قص الصمت يستخدم عتبة `-42 dBFS`، وأقل مدة صمت `250 ms`، وهامش أمان `65 ms`.

ملاحظة: نسبة الصمت النهائية 4% لم تُنفّذ كضمان حسابي في هذه المرحلة؛ النسبة المتبقية تختلف حسب الملف. هذه النقطة موثقة في `CHANGELOG_AR.md` و`REBUILD_BOARD_AR.md`.


## العمل في الخلفية
تُرسل مهام التفريغ وقص الصمت إلى عامل خلفي واحد. حالة كل مهمة تُحفظ في `temp/jobs/`، والنتائج في `outputs/`. حدّث الصفحة أو أغلق تبويبها ثم عد إلى التطبيق ما دام خادم Python يعمل.

**حد الاستمرارية:** العامل داخل عملية التطبيق؛ إيقاف الخادم أو نومه أو إعادة تشغيله قد يوقف المهمة. هذه النسخة ليست طابورًا خارجيًا دائمًا، لذلك لا تضمن إكمال المهام بعد إعادة تشغيل الاستضافة.


### هدف الصمت المتبقي
قص الصمت يستهدف إبقاء قرابة 5% من الصمت الطبيعي وفق معايرة مستوى الإشارة. النسبة تقديرية وقد تختلف باختلاف الضوضاء ومحتوى التسجيل؛ يلزم اختبارها على ملفات حقيقية قبل اعتبارها مطابقة بدقة لكل ملف.
